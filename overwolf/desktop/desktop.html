CoachBuild Overlay

League of Legends skill-order reference

Checking for League of Legends…

League's live client data doesn't reliably report your lane during a match, so this is what the in-game overlay uses to pick the right skill order.

Hotkeys

Ctrl + F10
Show / hide the overlay
Ctrl + F11
Make the overlay clickable (it starts click-through)
