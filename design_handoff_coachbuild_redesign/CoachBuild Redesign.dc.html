NOCTURNE · 1440×900 DESKTOP

A companion that follows the match, not a website in a window.

THE SPINE
A live phase rail — Lobby → Champ Select → In Game → Post Game — sits in the top bar on every screen and drives what the app shows you. The app's state is the game's state.
VERDICT FIRST
Every screen opens with one prescriptive answer at display size — pick this, build this, level this — with the table underneath for people who want to argue with it.
HONESTY KEPT
Sample size, low-data and "suggested" labels survive the redesign — they're rendered as quiet meta rather than removed, since they're the product's posture.
ASSUMPTIONS
Champion / item / rune art is a monogram placeholder — drop real assets in and they slot straight into the same tiles. Win/loss green + red are the only colors added outside Nocturne; stats need a signal hue.
